Política de Privacidade

Última atualização: 01 de junho de 2026

1. Introdução

O Agente de Impressão foi desenvolvido para permitir a comunicação entre aplicativos e impressoras Bluetooth compatíveis.

A privacidade dos usuários é importante para nós. Por isso, este aplicativo foi projetado para operar sem coletar, armazenar ou compartilhar dados pessoais.

2. Coleta de Dados

O Agente de Impressão não coleta, armazena, processa ou compartilha dados pessoais dos usuários.

Não coletamos informações como:

  • Nome
  • E-mail
  • Telefone
  • Endereço
  • Localização
  • Informações de pagamento
  • Dados de uso para fins de marketing
  • Dados para publicidade

3. Uso do Bluetooth

O aplicativo utiliza permissões de Bluetooth exclusivamente para:

  • Localizar impressoras Bluetooth próximas;
  • Estabelecer conexão com impressoras compatíveis;
  • Enviar comandos de impressão para os dispositivos selecionados pelo usuário.

As permissões Bluetooth não são utilizadas para rastreamento, publicidade ou coleta de informações pessoais.

4. Compartilhamento de Informações

O Agente de Impressão não compartilha informações com terceiros, pois não realiza coleta de dados pessoais.

5. Armazenamento de Dados

O aplicativo não mantém servidores próprios e não envia informações para serviços externos.

Eventuais configurações locais necessárias para o funcionamento do aplicativo permanecem armazenadas apenas no dispositivo do usuário.

6. Segurança

Embora o aplicativo não realize coleta de dados pessoais, adotamos boas práticas de desenvolvimento para garantir a integridade e o funcionamento adequado da aplicação.

7. Alterações nesta Política

Esta Política de Privacidade poderá ser atualizada periodicamente para refletir melhorias ou alterações no aplicativo.

A versão mais recente estará sempre disponível nesta página.

8. Contato

Em caso de dúvidas sobre esta Política de Privacidade, entre em contato através dos canais oficiais do desenvolvedor.

Resumo:
O Agente de Impressão não coleta, armazena, vende ou compartilha dados pessoais dos usuários. As permissões Bluetooth são utilizadas exclusivamente para conexão e comunicação com impressoras compatíveis.
